**Begrippenlijst**

| Begrip | Betekenis | Meervoud |
| --- | --- | --- |
| de kracht | een grootheid die een lichaam van vorm of van bewegingstoestand kan veranderen | de krachten |
| de wrijvingskracht | de kracht die de beweging van een lichaam tegenwerkt | de wrijvingskrachten |
| de vectoriële grootheid of de vector | een grootheid die gekenmerkt wordt door een aangrijpingspunt, een richting, een zin en een grootte | de vectoriële grootheden of vectoren |
| het aangrijpingspunt | het punt waar een kracht inwerkt op een ander lichaam | de aangrijpingspunten |
| de richting | de werklijn waarlangs een kracht werkt (horizontaal, verticaal of schuin) | de richtingen |
| de zin | naar welke kant een kracht haar uitwerking heeft (naar rechts, naar boven …) | de zinnen |
| de grootte | getal dat weergeeft hoe groot een kracht is, uitgedrukt in newton | de groottes |
| de resulterende kracht of de resultante | een kracht die hetzelfde effect heeft als twee of meerdere krachten samen | de resulterende krachten of resultanten |
| de component | één van de krachten waaruit de resultante samengesteld is | de componenten |
| de snelheidsvector | een vectoriële grootheid gekenmerkt door een aangrijpingspunt, een richting, een zin en een grootte | de snelheidsvectoren |
| de traagheid | Een lichaam wil zijn bewegingstoestand blijven behouden. |  |
| de traagheidswet | Als de grootte van de resulterende kracht op een voorwerp nul newton is, behoudt het zijn bewegingstoestand. |  |
| het veld | het gebied waarin krachten werkzaam zijn | de velden |
| de veldkracht | een kracht die werkt op afstand dus zonder contact tussen twee lichamen | de veldkrachten |
| de zwaartekracht | de aantrekkingskracht die een hemellichaam uitoefent op alle lichamen in zijn omgeving |  |
| het zwaarteveld | het gebied rond een hemellichaam waar de zwaartekracht werkzaam is | de zwaartevelden |
| het zwaartepunt | het aangrijpingspunt voor de zwaartekracht | de zwaartepunten |
| de zwaarteveldsterkte | Dit is een maat voor de sterkte van het zwaarteveld. Het is ook de constante verhouding tussen de zwaartekracht op een lichaam en de massa van dat lichaam. | de zwaarteveldsterktes |
| de massa | een maat voor de hoeveelheid materie waaruit een lichaam bestaat | de massa’s |
| het gewicht | de kracht die een lichaam uitoefent op zijn steunpunt of ophangpunt | de gewichten |
| het steunpunt | de ondergrond waar een lichaam een gewicht op uitoefent | de steunpunten |
| het ophangpunt | de plaats waar een hangend lichaam een gewicht op uitoefent | de ophangpunten |
| gewichtloos | een lichaam dat geen gewicht heeft omdat het niet ondersteund wordt of geen ophangpunt heeft |  |
| de normaalkracht | de loodrechte kracht die een steun uitoefent op een lichaam | de normaalkrachten |
| de statische wrijvingskracht | de kracht die ervoor zorgt dat een lichaam dat in rust is ten opzichte van de ondergrond, niet in beweging komt | de statische wrijvingskrachten |
| de maximale statische wrijvingskracht | de kracht die op het lichaam inwerkt vlak voor het vanuit rust in beweging komt | de maximale statische wrijvingskrachten |
| de dynamische wrijvingskracht | de wrijvingskracht tussen het lichaam dat beweegt en de ondergrond | de dynamische wrijvingskrachten |
| de statische wrijvingscoëfficiënt | de constante verhouding tussen de maximale statische wrijvingskracht en de normaalkracht | de statische wrijvingscoëfficiënten |
